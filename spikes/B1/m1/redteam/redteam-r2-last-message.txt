10. **NEW — MAJOR — M1.1, M1.7: The tool does not enforce the amendment’s single-deposit scope.** M1 mode still accepts repeated `--deposit` arguments and any deposit satisfying the generic seal checks. It never compares the input archive hash against the amendment’s pinned `f95155af…` identity. The existing `--tarball-sha` check concerns the internal tarball manifest and does not enforce that deposit identity. A correctly pinned amendment can therefore label a score computed from different or combined inputs. **Fix:** in M1 mode, require exactly one deposit and verify its full pinned SHA-256 before extraction or scoring. Preserve generic multi-deposit behavior only outside M1 mode.

11. **NEW — MAJOR — M1.2, M1.7–M1.9: The implementation substitutes a recomputation for the immutable original record.** `m1_rescore()` sets `v10_outcome_of_record` from the current recomputation, and `m1_write()` prints that value as `v10_outcome`. If an inherited check fails, this becomes null even though the historical outcome remains INCONCLUSIVE. The JSON also omits the original per-run AULCs promised for side-by-side comparison; it retains recomputed point returns and an aggregate line instead. **Fix:** embed or load the hash-verified original record separately, preserve its original line and outcome unconditionally, and include the promised original curves/AULCs. Label recomputation separately and report discrepancies without replacing historical fields.

12. **NEW — MAJOR — M1.7, M1.9: The original-file overwrite guard is incomplete.** The guard checks `--out` only against `results.json` and `--runs-log` only against `runs.log`. Passing `--out spikes/B1/runs.log` can truncate the original log; passing `--runs-log spikes/B1/results.json` can append to the original results. Path aliases can also bypass the string comparisons. **Fix:** validate both output destinations against both protected files using canonical paths and file identity where applicable, reject identical output destinations, and complete these checks before scoring or writing.
